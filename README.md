# DS_MLB_Project
In this project, I will work on the long term trends in Major League Baseball batting performance, focusing on how batting averages have declined in recent years. Recent years have seen some of the lowest batting averages in MLB history,while pitching velocity, and pitching design has improved. 

This project will answer the following questions:

1. How has pitch-level velocity changed over the years?
2. How have strikeouts per game and ERA changed in recent seasons?
3. What is MLB’s average league-wide batting average, and how has it dropped over time?
